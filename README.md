# Saylani Welfare International Trust - Website

A modern, responsive website for Saylani Welfare International Trust, Pakistan's leading NGO dedicated to providing essential services in medical care, education, welfare, and health support to underprivileged families across Pakistan.

## 🌟 Features

### Core Sections
- **Hero Section**: Welcoming introduction with call-to-action buttons
- **Services Overview**: Showcasing four main service areas (Welfare, Medical, Education, Food)
- **Gallery Section**: Visual showcase of Saylani's work and impact
- **Testimonials**: Real stories from beneficiaries and volunteers
- **Contact & Feedback**: Interactive contact form with Google Maps integration
- **Footer**: Comprehensive navigation and social media links

### Interactive Elements
- **Chatbot Integration**: Google Dialogflow-powered chatbot for user assistance
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Contact Form**: Email and message submission functionality
- **Interactive Map**: Embedded Google Maps showing Saylani's location
- **Donation Buttons**: Multiple donation call-to-action points

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure
- **Tailwind CSS**: Utility-first CSS framework for styling
- **JavaScript**: Interactive functionality
- **Google Dialogflow**: AI-powered chatbot
- **Google Maps API**: Location integration
- **Responsive Design**: Mobile and desktop optimized

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required - all resources are CDN-hosted

### Installation & Running

1. **Clone the repository**
   ```bash
   git clone https://github.com/fazal-coder/Salyani-clone.git 
   cd Salyani-clone
   ```

2. **Open the website**
   - Simply open `index.html` in your web browser
   - Or use a local server for development:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     ```

3. **Access the website**
   - Navigate to `salyani-clone-fazal.vercel.app/` (if using a local server)
   - Or directly open `index.html` in your browser
